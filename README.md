# International dialing codes

How to dial every country from abroad: the calling code, what happens to the national trunk prefix (the leading 0 most countries use at home), and a real example number in both its local and international form, for **241 destinations**.

It is the open dataset behind [InternationalCall.co's dialing reference](https://internationalcall.co/call/international-dialing-codes), where each country with a guide links to it below. The numbering facts come from Google's [libphonenumber](https://github.com/google/libphonenumber) metadata, checked against each country's own numbering plan where the two disagree (Brazil and Colombia keep no trunk prefix, for example).

- `dialing-codes.csv` and `dialing-codes.json`: the same 241 records.
- Fields: `country`, `iso2`, `callingCode`, `dialCode`, `exampleLocal`, `exampleInternational`, `trunkAction` (`drop`, `keep` or `none`), `trunkPrefix`, `trunkApplies`, `trunkRule` (the rule in one sentence) and `guide` (the country's dialing guide, when there is one).
- Archived with a DOI on Zenodo: [10.5281/zenodo.23105930](https://doi.org/10.5281/zenodo.23105930).
- Generated 2026-11-27 from the live dataset. The live, always-current version is at [https://internationalcall.co/call/international-dialing-codes/data](https://internationalcall.co/call/international-dialing-codes/data) (JSON, or `?format=csv`).
